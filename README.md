# AI Carousel Showdown

A side-by-side comparison of a simple carousel component built by different AI models from a single prompt.

## The Prompt

Each model was given the same prompt to build a **Process Tips Carousel** — a UI component displaying tip cards with navigation controls.

Compare output quality, code structure, accessibility, and design fidelity across AI coding assistants given identical instructions.
